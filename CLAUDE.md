# CLAUDE.md

An exploration of limit order books in C++, built from the cpp-starter
template like C1M (`../C1M`). It is learning material for a series on the
blog, a sibling at `../my-blog`, whose own `CLAUDE.md` sets the writing
rules: the author drafts every post, and Claude verifies, scaffolds and
captures real command output.

- `README.md` holds the goals and how to build, test and run everything.
- Every number quoted anywhere comes from a run that can be repeated with the
  command next to it.
